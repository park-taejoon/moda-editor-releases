# 사용자 가이드

`starterFeatures()` 프리셋 + 데모 크롬(`.me-toolbar`) 기준의 편집
조작법 정리다. `Ctrl/Cmd`는 Windows/Linux는 `Ctrl`, macOS는 `Cmd`를
뜻한다.

## 툴바

버튼 순서는 GDocs/TinyMCE 관례다 — 실행취소 → 블록 서식 → 인라인
서식 → 스타일 패널 → 정렬 → 목록/인용 → 삽입 → ⋯ 오버플로.

- **블록 서식 드롭다운** — 본문/제목 1~3. 캐럿이 있는 블록의 현재
  서식을 보여준다 (GDocs paragraph-style 관례)
- **A▾ 스타일 패널** — 글자색, 형광펜, 글자 크기, 위/아래 첨자,
  서식 지우기
- **⋯ 오버플로** — 구분선, callout, 검색, 멘션,
  코드블록 보조(공백 표시·줄바꿈), 테마 피커. 표 안에 캐럿이
  있을 때만 행/열 추가·삭제·표 삭제 버튼이 추가로 나타난다
- **상태바 에디터/마크다운 탭** — 프레임 우하단 상태바의 뷰 전환
  탭이다 (VS Code editor|preview 관례). `마크다운`을 누르면
  에디터 영역 전체가 편집 가능한 Markdown 소스 뷰로 바뀐다 —
  툴바가 아니라 에디터 크롬의 영역이다
- **좁은 화면** — 항목을 숨기지 않고 툴바가 두세 줄로 감긴다.
  ⋯ 버튼은 첫 줄 우측에 고정돼 항상 같은 위치다

서식 토글(굵게·기울임 등)은 GDocs/Word처럼 **눌러두기**다 —
버튼을 누른 뒤 커서를 옮겨도 꺼지지 않고, 같은 버튼을 다시
누르거나 서식 지우기를 할 때만 해제된다. 코드블록 안에서는 서식이
적용되지 않는다(코드는 항상 무장식).

선택 없이 `</>`(인라인 코드)를 누르면 캐럿 자리에 `</>` 힌트가
옅게 뜬 빈 칩이 먼저 놓인다 (Notion 관례) — 바로 타이핑하면
칩 안에 코드가 채워진다. 칩을 비운 채 캐럿이 나가면 칩은 사라진다.

## 키보드 단축키

### 텍스트 서식

| 단축키             | 동작          |
| ------------------ | ------------- |
| `Ctrl/Cmd+B`       | 굵게          |
| `Ctrl/Cmd+I`       | 기울임        |
| `Ctrl/Cmd+U`       | 밑줄          |
| `Ctrl/Cmd+Shift+S` | 취소선        |
| `Ctrl/Cmd+E`       | 인라인 코드   |
| `Ctrl/Cmd+K`       | 링크 (팝오버) |
| `Ctrl/Cmd+.`       | 위첨자        |
| `Ctrl/Cmd+,`       | 아래첨자      |

### 편집·이동

| 단축키                            | 동작                                                             |
| --------------------------------- | ---------------------------------------------------------------- |
| `Ctrl/Cmd+Z`                      | 실행 취소                                                        |
| `Ctrl/Cmd+Shift+Z` / `Ctrl/Cmd+Y` | 다시 실행                                                        |
| `Shift+Enter`                     | 줄바꿈 (같은 블록 안)                                            |
| `Ctrl/Cmd+Enter`                  | 닫힌 블록 탈출 — 코드블록·인용구·callout 뒤 본문으로             |
| `Tab` / `Shift+Tab`               | 표 안: 다음/이전 셀 — 코드블록·리스트 안에서는 들여쓰기/내어쓰기 |
| `Home`/`End`                      | 시각적 줄 처음/끝 (긴 줄이 wrap돼도 시각 줄 기준)                |
| `Ctrl/Cmd+←/→`                    | 줄·문서 경계 이동                                                |

문서 끝에는 항상 빈 문단이 보장된다 — 콜아웃·표·구분선 같은 블록이
마지막이어도 그 아래에 바로 커서를 두고 타이핑할 수 있다
(ProseMirror `trailingNode` 관례).

### 코드블록 안

| 단축키              | 동작                                      |
| ------------------- | ----------------------------------------- |
| `Tab` / `Shift+Tab` | 들여쓰기/내어쓰기 (여러 줄 선택 가능)     |
| `Ctrl/Cmd+/`        | 줄 주석 토글 (언어별 문법)                |
| `Alt+↑/↓`           | 줄 위/아래 이동                           |
| `Ctrl/Cmd+Shift+D`  | 줄 복제                                   |
| `Ctrl/Cmd+Enter`    | 코드블록 뒤 본문으로 탈출                 |
| `↑`/`↓` 경계        | 첫 줄 위/마지막 줄 아래에서 화살표로 탈출 |

자동 쌍(`()`/`[]`/`{}`/`""`/`''`/` ` ``), 괄호 매칭 하이라이트,
선택 영역 괄호 감싸기가 기본으로 켜져 있다.

## Markdown 입력 규칙

타이핑만으로 서식이 변환된다 — 블록 마커는 줄 맨 앞에서만
동작한다 (Notion/Typora 관례).

| 입력                  | 결과        |
| --------------------- | ----------- |
| `**텍스트**`          | 굵게        |
| `*텍스트*` `_텍스트_` | 기울임      |
| `~~텍스트~~`          | 취소선      |
| `` `텍스트` ``        | 인라인 코드 |
| `[텍스트](url)`       | 링크        |
| `# ` … `###### `      | 제목 1~6    |
| `- ` `* ` `+ `        | 글머리 목록 |
| `1. `                 | 번호 목록   |
| `[ ] ` `[x] `         | 할일 목록   |
| `> `                  | 인용구      |
| `---`                 | 구분선      |
| ` ``` `               | 코드블록    |

선택된 텍스트 위에서 `` ` ``를 누르면 문자가 입력되는 대신
선택이 인라인 코드로 감싸진다 (Slack/Discord 관례).

## 블록 조작

- **드래그 이동** — 블록에 마우스를 올리면 좌측에 드래그 핸들이
  나타난다. 잡아 끌면 삽입 경계에 라인이 표시되고 놓은 위치로
  블록이 옮겨간다
- **버블 메뉴** — 텍스트를 드래그해 선택하면 위에 인라인 서식
  버블이 뜬다
- **할일 목록** — 마커(☐) 클릭으로 체크 토글

## 삽입물

- **표** — ▦ 버튼의 크기 그리드로 삽입. 캐럿이 표 안에 있으면
  표 위에 행/열 추가·삭제 바와 열 너비 조절 핸들이 뜬다
  (`Tab`=다음 셀)
- **이미지** — ⛶ 버튼 → URL 붙여넣기 또는 파일 선택. 삽입되면
  이미지가 선택 상태로 들어와 편집·교체·삭제 바와 우하단 크기
  핸들이 바로 뜬다 (이후에는 이미지를 클릭해 다시 연다).
  `편집`은 주소/대체 텍스트를 바꾸고 `적용`(또는 `Enter`)으로
  반영한다
- **코드블록** — `{ }` 버튼이나 ` ``` ` 입력. 우측 상단 크롬에서
  언어 선택·서식 정리·복사를 지원한다. 커스텀 nodeView가
  등록된 앱은 그쪽 UI가 대신 그려진다
- **링크** — `Ctrl/Cmd+K` 또는 `[텍스트](url)` 입력. 캐럿이
  링크 위에 있으면 하단에 미리보기 카드가 뜬다
- **구분선** — `---` 입력 또는 ⋯ 메뉴
- **callout** — ⋯ 메뉴 (커스텀 노드 예시). 바로 아래 문단 맨 앞에서
  `Backspace`를 누르면 텍스트 머지 대신 컴포넌트가 통째로
  선택되고(선택 링) 한 번 더 누르면 삭제된다 — `Delete`도
  대칭으로 동작한다 (ProseMirror/Tiptap 관례)
- **멘션** — ⋯ 메뉴의 `@` — 이름 입력 팝오버가 뜨고 Enter로
  `@이름` 칩을 삽입한다. 칩은 통째로 선택/삭제되는 인라인 atom이다

## 검색/치환

⋯ 메뉴의 🔍 버튼은 Chrome/GDocs식 찾기 바를 에디터 우상단에
고정으로 띄운다 — 검색어를 치는 즉시 모든 매치가 형광
하이라이트되고 `n/total` 카운터가 뜬다.
타이핑하는 동안 커서도 입력 포커스도 움직이지 않는다 — `↑`/`↓`
버튼이나 `Enter`/`Shift+Enter`를 누르면 현재 매치가 진한
하이라이트로 표시되며 화면이 따라간다. 아래 줄의 바꾸기 칸에
치환어를 넣고 **치환**(현재 매치, Enter)·**전체**(모든 매치)로
바꿀 수 있다 — 치환은 undo 한 단위로 되돌아간다.
창을 닫으면(`✕`/`Esc`/바깥 클릭) 검색과 하이라이트가 함께
해제되고 커서는 마지막 매치에 놓인다.

## 붙여넣기와 내보내기

- **Markdown 붙여넣기** — 클립보드의 `text/plain`이 마크다운
  신호(블록 마커/인라인 구분자)를 가지면 자동으로 문서 구조로
  변환된다. HTML 클립보드(앱 내 복사 등)는 항상 HTML 경로가 우선
- **Markdown 소스** — 상태바 우측의 `에디터 | 마크다운` 탭에서
  `마크다운`을 누르면 에디터 영역이 문서 전체의 마크다운 소스
  뷰로 전환된다. 치는 대로 문서가 즉시 갱신되고(Typora 소스
  편집 관례) 데모 콜아웃은 `> [!NOTE]` 알림 구문으로 왕복
  보존된다 — 복사 버튼으로 가져가도 된다. `에디터` 탭이나
  `Esc`로 돌아온다 (IME 조합 중 `Esc`는 조합 취소다)

## 테마

⋯ 메뉴의 `◐`가 테마 피커를 연다 — 스와치 미리보기 목록에서
심플·모던·다크(Monokai)·네온 다크·퍼플·퍼플 다크 프리셋을 고른다
(`기본`은 원래 라이트 팔레트). 선택은 localStorage에 저장돼
재방문 시에도 유지된다. 테마는 플랫한 `--me-*` 변수 맵이라 제품에서
커스텀 테마를 객체 하나로 만들어 `applyTheme`으로 적용할 수 있다 —
[테마 가이드](./theming.md) 참고.

## 협업

데모는 같은 브라우저의 두 탭/창을 BroadcastChannel로 연결한다 —
한쪽의 편집이 다른 쪽에 즉시 반영되고 상대 커서가 이름표와
함께 표시된다. 프로덕션 연동(y-websocket 등)은
[협업 가이드](./features/collab.md)를 본다.
